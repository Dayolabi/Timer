    Repeat blocks, saved plans, sharing and printing are on the Plans tab.

    Blocks with a clock time start at that time. Blocks set to “after previous” start as soon as the one before ends. Leave a length empty to run until the next pinned block. Drag the dotted handle to reorder. Shortcuts: Space starts and pauses, F toggles focus mode.

    Repeat blocks

    Copy a run of blocks several times. Block numbers are the ones in the coloured circles on the Today tab.

    The copies go right after the last block in the range, and each starts when the one before it ends.
